# Primeiro Projeto

An early Python learning project preserved as part of my development journey.

## About

This small command-line exercise was my first attempt at modeling a restaurant application. It displays a role-selection menu, validates numeric input and separates simple actions into Python functions.

It is not a complete restaurant-management system and is not presented as a current portfolio centerpiece. The repository remains public to show where my programming practice started and how later projects became more structured, tested and production-aware.

## Concepts Practised

- Python functions
- Conditional control flow
- Console input and output
- Basic input-error handling
- Organizing a script around a `main` entry point

## Run Locally

```bash
python "Primeiro Projeto.py"
```

## Status

Historical learning project. No active feature development is planned.
